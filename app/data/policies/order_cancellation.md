# Order Cancellation Policy

## 1. Eligible Cancellation Window
Customers can request to cancel an order only while it is in **PENDING** or **PAID** status, prior to warehouse fulfillment.
- Once an order transitions to fulfillment, packaging, or has a carrier tracking number assigned, it can no longer be cancelled.
- If cancellation is no longer possible, the customer must await package arrival and request a standard return.

## 2. Cancellation Process & Ineligibility
- Cancelled orders immediately release any inventory holds back to stock.
- If the order was already charged, a full refund including original shipping is initiated upon cancellation.
- Orders in **EXPIRED**, **CANCELLED**, or **REFUNDED** status cannot be re-cancelled.
- High-heat raffle drop wins cannot be cancelled once the raffle outcome has been decided.
