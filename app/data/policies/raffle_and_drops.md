# Exclusive Sneaker Drops & Raffle Entries

## 1. Participation Rules
- Each registered user is strictly limited to **one entry per sneaker drop** (`UNIQUE(user_id, drop_id)`).
- Multiple accounts detected from the same device, IP cluster, or billing address will be disqualified under anti-bot protection.
- Entries cannot be transferred, sold, or reassigned to another user account.

## 2. Entry Statuses & Outcomes
- **WON**: The user won the raffle selection. Payment is authorized and the order is created automatically.
- **LOST**: The user was not selected in the primary draw. No charge occurs.
- **WAITLISTED**: The user is placed in a numbered queue (position rank). If a winning user's payment fails within 15 minutes, waitlisted entries are promoted sequentially in order of position.

## 3. Post-Win Policy
- All raffle drop wins are **Final Sale**. No returns, refunds, or size exchanges are permitted unless an item arrives defective from manufacturing.
